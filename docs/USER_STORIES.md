# OpportunityHub User Stories

This document defines what each type of user should be able to do in the system.

---

# Student

## Registration

As a student,
I want to create an account,
So that I can use OpportunityHub.

---

## Login

As a student,
I want to log into my account,
So that I can access my profile and opportunities.

---

## Manage Profile

As a student,
I want to complete and update my profile,
So that companies can know more about me.

---

## Manage Skills

As a student,
I want to add, edit, and remove my skills,
So that the AI matching system can recommend suitable opportunities.

---

## Upload CV

As a student,
I want to upload multiple CVs,
So that I can choose the best one for each application.

---

## Browse Opportunities

As a student,
I want to browse all available opportunities,
So that I can find jobs, internships, volunteering opportunities, scholarships, and competitions.

---

## Search Opportunities

As a student,
I want to filter opportunities,
So that I can quickly find suitable ones.

Filters may include:

- Opportunity type
- Category
- Location
- Work mode
- Company
- Required skills

---

## View Opportunity Details

As a student,
I want to view complete opportunity details,
So that I can decide whether to apply.

---

## Apply

As a student,
I want to apply to an opportunity,
So that the company can review my application.

---

## Track Applications

As a student,
I want to view all my applications,
So that I know their current status.

---

## View Interview

As a student,
I want to view my interview details,
So that I know when and where to attend.

---

## Receive Notifications

As a student,
I want to receive notifications,
So that I never miss important updates.

---

# Company

## Registration

As a company,
I want to create a company account,
So that I can recruit candidates.

---

## Complete Company Profile

As a company,
I want to complete my company profile,
So that students know who we are.

---

## Publish Opportunities

As a company,
I want to publish jobs and internships,
So that students can apply.

---

## Manage Opportunities

As a company,
I want to edit, close, or reopen opportunities,
So that my listings stay updated.

---

## View Applicants

As a company,
I want to view everyone who applied,
So that I can select suitable candidates.

---

## View AI Matching

As a company,
I want to see the AI matching score,
So that I can review candidates more efficiently.

---

## Update Application Status

As a company,
I want to change the application status,
So that students know the result.

Possible statuses:

- Pending
- Reviewed
- Shortlisted
- Interview Scheduled
- Accepted
- Rejected

---

## Schedule Interview

As a company,
I want to schedule interviews,
So that I can meet selected candidates.

---

## Send Notifications

As a company,
I want students to receive automatic notifications after important actions.

---

# Admin

## Manage Users

As an admin,
I want to manage all users,
So that the platform remains secure.

---

## Approve Companies

As an admin,
I want to approve or reject company accounts,
So that only trusted companies can publish opportunities.

---

## Monitor Opportunities

As an admin,
I want to review opportunities,
So that inappropriate content can be removed.

---

## Manage Reports

As an admin,
I want to investigate reported content,
So that platform quality remains high.

---

## Dashboard

As an admin,
I want to view platform statistics,
So that I can monitor activity.

Statistics may include:

- Total users
- Students
- Companies
- Opportunities
- Applications
- Interviews

---

# AI System

## Candidate Matching

As a company,
I want applicants ranked by matching score,
So that I can identify the best candidates quickly.

---

## Opportunity Recommendation

As a student,
I want recommended opportunities,
So that I discover suitable opportunities automatically.

---

# Notifications

The system should automatically notify users when:

- Company account approved
- Opportunity published
- Application submitted
- Application reviewed
- Interview scheduled
- Application accepted
- Application rejected

---

# Future Features

- Saved Opportunities
- Favorite Companies
- Messaging between student and company
- Email Notifications
- Calendar Integration
- AI CV Improvement Suggestions
