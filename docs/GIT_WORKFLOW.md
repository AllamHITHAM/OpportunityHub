# OpportunityHub Git Workflow

## Main Branch

The `main` branch must always contain stable working code.

Do not work directly on `main` for large features.

---

## Feature Branches

Each developer should create a separate branch for their task.

Examples:

```bash
git checkout -b feature/student-profile
git checkout -b feature/company-profile
git checkout -b feature/opportunities
git checkout -b feature/applications
