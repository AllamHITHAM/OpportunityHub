# OpportunityHub Project Overview

## Project Name
OpportunityHub

## Project Type
Smart opportunity platform for jobs, internships, volunteering, scholarships, and competitions.

## Main Goal
OpportunityHub connects students/job seekers with companies and organizations through a structured platform that supports opportunity posting, applications, CV uploads, interview scheduling, notifications, and AI-based matching.

## Tech Stack
- Backend: Laravel 12
- Database: MySQL
- API: REST API
- Frontend: Flutter
- Testing: Postman
- Version Control: Git + GitHub

## User Roles

### 1. Student / Job Seeker
A student can:
- Register and login.
- Create and update student profile.
- Add skills.
- Upload CVs.
- Browse opportunities.
- Apply to opportunities.
- Track application status.
- View interview details.
- Receive notifications.

### 2. Company
A company can:
- Register and login.
- Create company profile.
- Wait for admin approval.
- Post opportunities.
- Add required skills to opportunities.
- View applicants.
- View matching scores.
- Update application status.
- Schedule interviews.
- Send notifications.

### 3. Admin
An admin can:
- Manage users.
- Approve or suspend companies.
- Manage opportunities.
- Monitor platform activity.
