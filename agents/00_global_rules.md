# OpportunityHub Global Rules

Project: OpportunityHub
Stack:
- Laravel 12
- MySQL
- REST API
- Flutter frontend later

Hard rules:
- Do not modify .env.
- Do not run migrate:fresh unless I explicitly approve.
- Do not run git push unless I explicitly approve.
- Do not delete files unless I approve.
- Do not change database design without asking.
- Work on one task at a time.
- Explain changed files briefly.
- Use Laravel conventions.
- Keep code clean and beginner-readable.
- Do not add packages unless necessary.
- Do not create duplicate migrations.
- Always check existing files before creating new ones.
